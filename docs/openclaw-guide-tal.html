What is OpenClaw?

1
OpenClaw is an open-source AI assistant that runs on your own computer. Unlike ChatGPT or other cloud services, you control everything — your data stays with you, and you can connect it to Telegram, WhatsApp, email, and more.

Why OpenClaw?

  • Privacy: Your conversations never leave your machine
  • Control: Customize behavior, add skills, connect to your apps
  • Multi-channel: Same bot on Telegram, WhatsApp, Discord, CLI
  • Persistent memory: Remembers context across sessions
  • Skills system: Add capabilities like calendar, email, home automation

What You'll Need

Hardware
  • Mac, Windows, or Linux computer
  • Always-on machine (or VPS) for 24/7 bot
  • 8GB RAM minimum recommended
Accounts
  • Anthropic API key (for Claude)
  • Or OpenAI/OpenRouter API key
  • Telegram account (for bot)

Installation

2

Step 1: Install Node.js

1 Download Node.js (v22+)
Visit nodejs.org and download the LTS version. Install with default options.
# Verify installation:
node --version # Should show v22.x.x
npm --version # Should show 10.x.x

Step 2: Install OpenClaw

2 Install via npm
# Install OpenClaw globally
npm install -g openclaw

# Verify installation
openclaw --version

Step 3: Initialize Your Workspace

3 Create workspace and configure
# Initialize OpenClaw (creates ~/.openclaw/)
openclaw init

# Set your API key
openclaw config set anthropic.apiKey YOUR_API_KEY

Step 4: Start Chatting

4 Launch the CLI
# Start OpenClaw in terminal
openclaw

# You can now chat with your AI assistant!
Getting an API Key
Go to console.anthropic.com, create an account, and generate an API key. You'll need to add a payment method — usage is typically $5-20/month for personal use.

Create Your Telegram Bot

3
Connect OpenClaw to Telegram so you can chat with your AI from your phone, anywhere in the world.

Step 1: Create Bot with BotFather

1 Open Telegram and find @BotFather
  • Open Telegram and search for @BotFather
  • Send /newbot
  • Choose a name: "Tal's Assistant"
  • Choose a username: tal_assistant_bot (must end in "bot")
  • BotFather will give you an API token — save it!

Step 2: Configure OpenClaw

2 Add your Telegram token
# Add Telegram bot configuration
openclaw config set telegram.botToken YOUR_BOT_TOKEN

# Optional: Restrict to your Telegram ID only
openclaw config set telegram.allowedUsers YOUR_TELEGRAM_ID

To find your Telegram ID, message @userinfobot on Telegram.

Step 3: Start the Gateway

3 Run OpenClaw as a service
# Start the gateway (keeps running in background)
openclaw gateway start

# Check status
openclaw gateway status

# View logs
openclaw gateway logs

Step 4: Chat!

4 Message your bot on Telegram
Find your bot on Telegram by its username and start chatting. Your AI assistant is now available on your phone 24/7!
Keep It Running
For 24/7 availability, run OpenClaw on an always-on machine (Mac mini, Raspberry Pi, or a VPS like DigitalOcean or Hetzner for ~$5/month).

Make It Yours

4

Workspace Files

Your OpenClaw workspace (~/.openclaw/workspace/) contains files that shape your assistant:

SOUL.md
Your assistant's personality. Edit this to change how it talks, what it prioritizes, and its general vibe.
USER.md
Information about you — name, preferences, timezone, contacts. Helps the AI understand context.
MEMORY.md
Long-term memory. The AI reads and writes here to remember important things across sessions.
TOOLS.md
Notes about your specific setup — API keys, local services, device names, etc.

Adding Skills

Skills add capabilities to your assistant. Browse and install from ClawHub:

# Search for skills
clawhub search calendar

# Install a skill
clawhub install apple-reminders

# List installed skills
clawhub list

Popular Skills

  • himalaya: Read and send emails
  • apple-reminders: Manage iOS/macOS reminders
  • apple-notes: Create and search notes
  • github: Manage repos, issues, PRs
  • weather: Get forecasts
  • imsg: Send iMessages (Mac only)

Useful Commands

openclaw status # Check system status
openclaw gateway restart # Restart the bot
openclaw config list # View all settings
openclaw help # Get help
