3

התקנה על המק

⏱️ 5 דקות

פתחי את Terminal (חפשי ב-Spotlight: ⌘+Space → Terminal)

קודם, התקיני Node.js:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

המתיני שזה יסתיים (כמה דקות)

brew install node

עכשיו, התקיני OpenClaw:

npm install -g openclaw

הפעילי את ההגדרות:

openclaw init

תתבקשי להדביק:

  • את הטוקן של הבוט (משלב 1)
  • את ה-API Key (משלב 2)
4

הפעלה!

⏱️ 30 שניות

ב-Terminal, כתבי:

openclaw start

עכשיו פתחי טלגרם, חפשי את הבוט שיצרת (@mibachutz_bot) ושלחי הודעה!

המק צריך להיות דלוק כדי שהבוט יעבוד. אם את סוגרת את המחשב, הבוט נעצר.
