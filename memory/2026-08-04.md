# Memory - August 4, 2026

## Mar Azul Interactive Map - Coyol Command (Morning)

### Task
Marion wanted the Mar Azul 2D interactive lot map (working on coyol-control) to also appear in coyol-command (coyolnosara.com/command).

### Problems Encountered
1. Initial lots.astro fetched from API (`coyol-control.vercel.app/api/mar-azul-lots.json`) at build time — failed on Vercel server-side rendering
2. Page showed "0 lots" and no interactive markers
3. Git push failed — no GitHub credentials configured on Mac
4. GitHub auth via device code timed out multiple times
5. Personal Access Token approach also failed
6. Spent significant time (~4 hours per Marion) on deployment issues

### Solution
1. Used Vercel CLI directly to deploy: `npx vercel --prod`
2. The lots page imports data from local JSON file (`../../data/mar-azul-lots.json`)
3. Markers rendered client-side after login

### Final Result
- **Live at:** https://coyolnosara.com/command/lots
- 35 lot markers on master plan image
- Summary cards (Total, Sold/Built, Available, Reserved, Processing)
- Click lot for details panel
- Search and table view
- Floating restaurant reservation buttons (La Luna + Coyol)
- Back button links to /command

### Deployment Notes
- coyol-website deploys to Vercel automatically via GitHub
- But git push requires GitHub auth (PAT token)
- Fallback: `npx vercel --prod` works directly
