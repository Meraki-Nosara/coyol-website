# Memory — May 18, 2026

## Coyol Control — User Permissions Fixed

**Issue:** Jorge and Gustavo couldn't upload files on the workflow page.

**Root Cause:** Supabase `app_users` table had incomplete permissions. Both users only had `{"viewDevWorkflow": true}` — missing `uploadFiles: true`.

**Fix:** Ran SQL UPDATE in Supabase to add full permissions:
```sql
UPDATE app_users 
SET permissions = '{"viewPublic":true,"viewOwnerInfo":false,"viewMedia":false,"viewLegal":false,"viewFinancials":false,"viewDevWorkflow":true,"uploadFiles":true,"editData":false,"deleteData":false,"manageUsers":false}'::jsonb
WHERE username = 'jorge';
-- Same for gustavo
```

**Users need to log out and back in** after permission changes (stored in sessionStorage).

- Gustavo: `gustavo` / `elec2026`
