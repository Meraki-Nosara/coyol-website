# Memory - July 28, 2026

## Reservation Confirmation Fix (Morning)

### Problem
Reservation confirmation emails stopped going out ~3 days ago (last sent July 25).
Isabel reported guests not receiving confirmations.

### Root Cause
The `/api/cron/reservations` entry was **removed from vercel.json** at some point.
Commit `9a98c958` removed it with message "Supabase edge function handles this now" — but the edge function wasn't actually working.

### Fix Applied
1. Added `/api/cron/reservations` back to vercel.json (every 15 min)
2. Committed and pushed: `4952de88`
3. Manually triggered cron to clear backlog

### Results
- **224 confirmation emails sent**
  - La Luna: 148 emails
  - Coyol: 76 emails
- No errors
- System back to normal

### Backups
Saved to `backups/coyol-website-2026-07-28/`:
- vercel.json (with cron restored)
- reservations.ts (cron endpoint)

### Lesson
Stick to ONE system (Vercel cron) — don't switch between Vercel and Supabase Edge Functions.
The cron approach with `email_sent` flag is simple and reliable.
