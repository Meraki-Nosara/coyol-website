## Afternoon Session (4:19 PM)

### Token Usage Investigation
- Marion reported ~5M tokens flying out even when not using computer
- **ROOT CAUSE FOUND:** Telegram config had `requireMention: false` for ALL groups (`"*"`)
  - This meant EVERY message in any Telegram group triggered AI processing
- **FIX:** Changed to `requireMention: true` for groups
- Also disabled heavy cron jobs:
  - `meraki-morning-check` — DISABLED (was daily 8am, does OCR/email parsing)
  - `meraki-daily-report` — DISABLED (was daily 8pm)
  - Weekly and monthly reports still enabled
- Marion needs to run `openclaw gateway restart` for changes to take effect

### La Luna Admin v2.7 → v2.8 Updates

#### 1. Booking Time Slots Feature (Settings)
- Added new "Booking Time Slots" section to settings page
- Staff can check/uncheck which times guests can book online
- Organized by "Dinner 1 (First Seating)" and "Dinner 2 (Second Seating)"
- Syncs to Supabase (`restaurant_settings` key: `laluna_time_slots`)
- Public reservation page (`reserve.astro`) dynamically loads only enabled slots

#### 2. Guest Database with Autocomplete
- Created `/api/laluna-guests.ts` — search API (requires min 2 chars, max 10 results)
- Auto-saves guests to `laluna_guests` table when reservations created
- Upserts on phone/email match, increments visit_count
- Admin new reservation form has autocomplete:
  - Type name → shows matching guests with visit count badges
  - Click to auto-fill name, phone, email
- Database builds up over time from new reservations

#### 3. Guest Privacy Protection
- **Rewrote `guests.astro`** — NO LONGER shows full guest list
- Staff cannot browse/export the database
- Only search-to-lookup functionality:
  - Search by name or phone
  - View selected guest's reservation history
  - No way to dump or copy full database
- API enforces: no search term = empty results

#### 4. Cancelled Reservations Excluded from Totals
- Fixed shift totals to exclude `cancelled` and `no-show` status
- Both per-shift counts and main totals now accurate
