## Helping Or Set Up TetraBot (Morning Session)

### The Problem
Or (a friend of Marion's) trying to connect his Telegram bot "TetraBot" to OpenClaw on his Mac.

### What We Tried
1. **Config commands failed** — `openclaw config set telegram.bots.tetra.token` gave "Unrecognized key" errors
2. **Wizard approach worked** — `openclaw config` → Channels → Telegram Bot API → entered token
3. **Bot connected but errored** — "Something went wrong while processing your request"
4. **Logs showed** — "Couldn't sign in to anthropic. Your saved login looks expired or no longer works."
5. **API key issue** — Old Anthropic key was invalid/expired
6. **Tried setting key via config** — Same schema error
7. **Tried ~/.zshrc export** — Gateway daemon doesn't inherit shell environment
8. **Tried ~/.openclaw/.env** — Didn't test this yet

### Decision: Fresh Install
After troubleshooting, decided clean install is faster:
```
openclaw gateway stop
npm uninstall -g openclaw
rm -rf ~/.openclaw
npm install -g openclaw
openclaw config
```
