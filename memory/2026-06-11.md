# Memory — June 11, 2026

## Late Night Debug Session with Marion (23:35-23:59)

### Helping Orrrrr's Bot "orbot"

Marion asked for help fixing his friend Orrrrr's OpenClaw bot that was stuck with error:
> "LLM request failed: provider rejected the request schema or tool payload"

**Investigation revealed:**
1. orbot runs on Orrrrr's MacBook laptop (2024 model)
2. `openclaw` command wasn't found — PATH issue
3. npm permission error (EACCES) when trying to reinstall
4. Fixed with `sudo npm install -g openclaw` — installed to `/usr/local/lib/node_modules/`
5. Gateway restarted successfully

**But still failing after restart.** Further diagnosis:
- Session was using model `claude-sonnet-4-6` — suspicious model string (should be `claude-sonnet-4`)
- Config file at `~/.openclaw/config.yaml` was **completely empty**!
- Orrrrr had changed from opus to sonnet but model name was wrong

**Solution in progress:**
- Add `model: anthropic/claude-sonnet-4` to the empty config.yaml
- Then `openclaw gateway restart`

**Note:** Orrrrr worked with orbot for 2 days creating stuff before it broke. The empty config is strange — need to figure out if there's another config location or if setup was incomplete.

### Key Learnings
- `claude-sonnet-4-6` is not a valid model name (causes schema rejection)
- Empty config.yaml can cause LLM schema errors
- When `openclaw` command not found on Mac, check npm permissions and use `sudo npm install -g openclaw`
