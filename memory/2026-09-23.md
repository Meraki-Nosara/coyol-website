## Coyol Restaurant Admin — Major Fixes Session

### Issues Found & Fixed

1. **Multi-table reservations not saving** — The `selectedTables` array was global and shared between modals. Tables weren't being properly added when checked.

2. **Cancelled reservations counted in totals** — The stats were including cancelled/no-show reservations in guest counts. Fixed to exclude them.

3. **Floor plan not showing multi-table bookings** — The filter `r.tableId === table.id` didn't work for comma-separated IDs like `"t5,t6"`. Created `resIncludesTable()` helper.

4. **Pax dropdown maxed at 20** — Large groups (22+) showed as "1p". Expanded to 50.

5. **Gift card indicator** — Changed from "GC" prefix to 🎁 emoji suffix (matching La Luna).

6. **Table naming conflicts** — Duplicate table numbers across zones (e.g., "Table 1" in both Inside and Jardin). Renamed all tables:
   - Inside: I1, I2, I3, I4, I5, I6, I-Sofa, I-Bar1/2/3
   - Terraza: T20-T28 (unchanged)
   - Jardin: J1-J9, J-Sofa, J-Sofa1

7. **Table dropdown disorganized** — Tables were listed in random order. Fixed to group by zone with headers: INSIDE, TERRAZA, JARDIN — sorted numerically within each zone.
